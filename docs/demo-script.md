# 5–10 minute demo flow

1. Start PostgreSQL and backend, then the React frontend.
2. Paste `data/sample_complaints/apollo_discoloration.txt` into Copilot.
3. Show automatic population of customer/product/batch/quantity/date/category fields.
4. Show AI risk assessment and completeness score.
5. Send: `batch number is BMX240602 and affected quantity is 48 capsules`.
6. Show the form updating without creating a second record.
7. Upload `metformin_foreign_matter.txt` or a synthetic PDF created from the same text.
8. Show critical risk classification and recommended next action.
9. Show duplicate detection, root cause and CAPA cards.
10. Commit to QMS Ledger and show the ledger ID plus audit timeline.
11. Walk through React, FastAPI, LangGraph and PostgreSQL folders in the repository.
